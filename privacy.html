Privacy Policy

Shorts Factory

Last updated 10 September 2026

Shorts Factory is a command-line program run by a single person on their own computer to publish videos to their own YouTube channel. It has no other users and no server. This policy describes exactly what data it touches and where that data goes.

In short: everything stays on the operator's machine. Nothing is sold, shared, transmitted to a third party, or used for advertising. There is no analytics, no tracking, and no other user whose data could be involved.

Data the operator's Google Account grants access to

When the operator signs in, they grant this program the following scopes for their own YouTube channel only:

ScopeWhy it is needed
youtube.upload To upload the finished video file to the operator's channel.
youtube To set a video's title, description, and scheduled publish time, and to change its privacy status from private to public at the scheduled moment.
yt-analytics.readonly To read view counts and retention figures for the operator's own uploads, so the program can report which videos performed well.

This access is used only to act on the operator's own channel. The program does not read, modify, or store data belonging to any other Google Account.

What is stored, and where

All of the following is written to the operator's own computer. None of it is uploaded anywhere.

  • Google credential. A refresh token, stored in a local file (secrets/token.json), so the program can upload on a schedule without prompting for sign-in each time. It is never transmitted except to Google's own authentication servers.
  • Video job records. A local SQLite database holding the scripts, shot lists, and publishing status of videos the operator has produced.
  • Cost records. Local records of what each video cost to generate, so the operator can track spending.
  • Generated media. Images, audio, and finished video files, stored in a local folder.

Public YouTube data

The program also reads publicly available information about videos on other public channels, using a Google API key and no user credential. This is limited to information anyone can see on YouTube without signing in:

  • Video title, duration, and publication date
  • Public view, like, and comment counts
  • The channel's public name and identifier

This is used to observe which video formats and lengths are currently performing, and is stored locally in a summary file. No private data is accessed, no personal information is collected, and no video content is downloaded, copied, or reproduced. Only metadata is retained.

What is not collected

  • No data is collected from visitors to this website. It is a set of static pages with no cookies, no analytics, and no tracking of any kind.
  • No personal information belonging to anyone other than the operator is stored.
  • No data is sold, rented, shared, or disclosed to any third party.
  • No data is used for advertising, profiling, or training machine-learning models.

Third parties

The program communicates with Google's YouTube APIs in order to upload videos and read the operator's own analytics. It may also call a text-generation service and a media- generation service to draft scripts and produce images. Those services receive only the prompt text needed to generate that material — they never receive the operator's Google credential or any YouTube account data.

Retention and deletion

All data is held locally and for as long as the operator keeps it. The operator can remove everything at any time by:

  • Deleting the local secrets/ and data/ folders, which removes the stored credential and all records; and
  • Revoking this program's access at myaccount.google.com/permissions, which invalidates the credential at Google's end.

Limited Use disclosure

Shorts Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the revised version will be posted on this page with an updated date above.
