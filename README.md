# shorts-factory-policy

Public home page, privacy policy and terms of service for **Shorts Factory**, a personal
single-operator tool that publishes video to one YouTube channel.

These pages exist to satisfy the Google Auth Platform "App domain" fields required to move
an OAuth consent screen out of Testing status. They describe real behaviour — if the tool's
data handling changes, update `privacy.html` to match.

Served via GitHub Pages from the `main` branch, root folder.
